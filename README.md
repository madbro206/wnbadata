# wnbadata

The code behind my WNBA and women's college basketball videos on
[TikTok](https://www.tiktok.com/@wnbadata) and [Instagram](https://www.instagram.com/wnbadata/).

I'm Maddy! I make short video explainers about women's basketball stats, and almost
every one of them starts as a script in here. This repo is mostly just an archive: 180+
projects going back to early 2024, one folder or file per video, mostly R with some
Python notebooks.

It is deliberately messy, so pls don't take these too seriously rn. These are the actual files I wrote while making each video,
not usually cleaned up afterward. Expect hardcoded numbers, half-finished ideas, and the
occasional (extremely common) thing that did not make it to camera.

**Looking for the polished version?** [wnba-analysis](https://github.com/madbro206/wnba-analysis)
is where I write things up properly, with a README, charts, and an explanation of what
I found for each project.

## Finding things

Files are named by date, `YYYY-M-D description`, so they sort roughly in the order the
videos went out. A few bigger projects have their own folder with the script, the data,
and the graphics.

## Data

Mostly [wehoop](https://wehoop.sportsdataverse.org/) for play by play and box scores,
plus [Her Hoop Stats](https://herhoopstats.com/) and Sports Reference depending on the
question. When any numbers came from somewhere else, hopefully the script says so :)
